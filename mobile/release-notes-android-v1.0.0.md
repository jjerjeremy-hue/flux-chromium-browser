## Flux Browser Android Preview 1.0.0

This is a free, installable Android preview APK distributed outside Google Play. It is signed with Android's debug certificate for preview use and is not a Play Store production build.

To install, download the APK on your Android device and open it. Android may ask you to allow installs from the app you used to open the file. Only install APKs from the official Flux Browser GitHub release page.

This mobile preview includes browser tabs, private tabs, bookmarks, local history, and address/search navigation. Mobile profile sync is not included.
